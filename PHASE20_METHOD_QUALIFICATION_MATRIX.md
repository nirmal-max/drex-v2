| State | Definition | Applied To |
|:---|:---|:---|
| **IMPLEMENTED** | Code, UI, dispatchers, backend adapters, and models exist in repository. | All 25 Methods (M01–M25) |
| **EXECUTABLE** | Method can execute end-to-end against disk images, directory trees, files, or supported hardware. | M01, M02, M07, M08, M09, M10, M11, M12, M13, M14, M15, M16, M17, M18, M19, M20, M21, M22, M23 (Virtual), M24, M25 |

| **HARDWARE_REQUIRED** | Method requires direct physical access to ATA/NVMe/SAS controllers or unmounted physical drive hardware. | M03, M04, M05, M06 (Live Disks); M01, M07, M23, M24 (Live Multi-Drive/Damaged Hardware) |
| **PRIVILEGE_REQUIRED** | Method requires elevated administrative / kernel storage driver access on Windows (`\\.\PhysicalDriveX`). | M01, M03, M04, M05, M06, M07 (When targeting live physical disks) |
| **PARTIAL** | Method execution performs logical envelope key invalidation (M09) or virtual RAID image reconstruction (M23) rather than full hardware ASIC execution. | M09, M23 |
| **FIXTURE_ONLY** | Method validated using multi-image or synthetic disk fixtures. | M23 |
