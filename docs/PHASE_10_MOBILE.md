# PHASE 10 MOBILE COMPANION SPECIFICATION

## 1. Role & Intentional Architecture

DREX Mobile is an **operational companion**, not a shrunken desktop workstation:
- Touch-first responsive interface ($\le 768\text{px}$) with persistent bottom navigation bar.
- Direct privileged hardware operations are **strictly prohibited** on mobile.
- Focuses on:
  1. Active case monitoring and investigator notes.
  2. Live progress meters for ongoing recovery and sanitization tasks.
  3. Remote dual-control authorization and destructive operation sign-off.
  4. Evidence candidate inspection with 5-factor confidence explainability.
  5. Offline capability limited to cached static assets and non-sensitive metadata (Correction 3).
