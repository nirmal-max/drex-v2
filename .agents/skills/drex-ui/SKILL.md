# DREX UI Skill

## When to Use
Use when constructing or updating UI pages, technical evidence cards, live progress meters, or dialog windows.

## Design Rules
- Palette: `#007AFF` (Blue), `#111827` (Ink), `#F5F5F7` (Background), `#FFFFFF` (Cards), `#34C759` (Success), `#FF3B30` (Destructive/Danger).
- Typography: Clear system typography with consistent hierarchy.
- Layout: Top workstation bar, persistent sidebar navigation (25 specialized pages), centered evidence viewport.
