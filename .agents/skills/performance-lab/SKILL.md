# Performance Lab Skill

## When to Use
Use when measuring read/write throughput (MB/s), CPU utilization across worker threads, and memory consumption during deep disk carving.

## Benchmarks
- Sequential vs random overwrite speeds.
- Carving throughput across multi-gigabyte disk images.
- Task manager queue latency and throttle controls.
