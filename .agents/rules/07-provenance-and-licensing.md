# Provenance and Licensing Policy Rule

## Directives
1. **Source Provenance Tracking**: Every reused external component must be registered in `docs/competitors/SOURCE_PROVENANCE_LEDGER.md`.
2. **License Compliance**:
   - **Apache-2.0 / MIT / BSD**: Maintain copyright notices and include text in `THIRD_PARTY_NOTICES.md`.
   - **GPL-2.0 / Copyleft**: Subprocess invocation via CLI adapters only; do not statically link GPL code into proprietary cores.
3. **No Unattributed Ingestion**: Code from external SIH repositories must be adapted to DREX architecture with full provenance attribution.
